# Tu copia del libro

Si quieres que el tutor de IA use el libro *Kubernetes: Érase Una Vez* como referencia, copia aquí tu PDF o EPUB.

1. Descarga el libro en Leanpub: <https://leanpub.com/erase-una-vez-kubernetes>. Puedes pagar lo que quieras, desde 0 €.
2. Copia el fichero en esta carpeta, por ejemplo `book/erase-una-vez-kubernetes.pdf`.
3. Abre el tutor desde la raíz del repositorio y empieza con `/estudiar pods`.

Esta carpeta está en `.gitignore`: tu copia del libro nunca se sube a git ni se comparte. Solo este fichero forma parte del repositorio.

Sin el libro, el tutor trabaja con las guías de la carpeta `study/`.
